# Dino Launcher — descargas

Modpacks y servidor, listos de una vez. Abres, inicias sesión y juegas: sin instalar
mods, sin buscar la IP, sin configurar nada.

**[→ Descargar la última versión](https://github.com/dinopolllo/dino-launcher-releases/releases/latest)**

| | Archivo |
|---|---|
| Windows | `dino-launcher_<versión>_x64-setup.exe` |
| macOS | `dino-launcher_<versión>_universal.dmg` (Intel y Apple Silicon) |

Se actualiza solo: cuando haya una versión nueva, el propio launcher te avisa y la
instala con un botón. Solo hace falta descargar a mano la primera vez.

## La primera vez, tu sistema va a desconfiar

El launcher no está firmado con un certificado comercial, así que Windows y macOS
avisan de que no conocen a quien lo hizo. No es que detecten nada malo: es que un
certificado cuesta dinero y esto es un proyecto de amigos.

**Windows** — sale una pantalla azul de SmartScreen. Pulsa *Más información* y luego
*Ejecutar de todas formas*.

**macOS** — no hagas doble clic la primera vez. Clic derecho sobre la app, *Abrir*, y
confirma en el diálogo. A partir de ahí abre normal.

## Qué es esto

Aquí solo viven las descargas. El código fuente está en otro repositorio.

Dino Launcher usa [ElyPrismLauncher](https://github.com/ElyPrismLauncher/Launcher) como
motor, sin modificarlo, descargándolo de sus releases oficiales. ElyPrismLauncher y
Prism Launcher son de sus respectivos autores bajo GPL-3.0. Este proyecto no está
afiliado ni respaldado por Prism Launcher, ElyPrismLauncher, Ely.by ni Mojang.
